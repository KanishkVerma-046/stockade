ほぼ全員が一度はやってしまう取引があります。ある銘柄が1週間激しく上昇しました。チャートにRSIを追加すると78を示しており、あのルールを思い出します: 70超えは買われすぎ、買われすぎは売り。そこで空売りします。その後2週間でその銘柄はさらに22%上昇し、RSIは68を下回ることなく、あなたは狙っていた値幅より大きな損失を出して買い戻すことになります。

そのルールが厳密に間違っていたわけではありません — あなたが、それが何を意味するかについて間違った考えを持っていただけです。RSI 78は、マーケットが反転が来ると告げているのではありません。14本のバーにわたって買い手が売り手を圧倒し続けていることを示しているのであり、それは弱さの予測ではなく強さの描写です。それを売りシグナルとして取引することは、画面上で最も強いものに対して体系的に逆張りすることを意味します。

## RSIが実際に測っているもの

相対力指数（RSI）は、J・ウェルズ・ワイルダーが1978年に発表した指標で、1つの狭い問いに答えます: 過去N本のバーにおいて、平均的な上昇幅は平均的な下落幅と比べてどうか？ 実際、それがすべてです。ルックバック期間（デフォルトでは14本）における各バーの終値の変化を上昇と下落に分け、それぞれを平均し、RS（relative strength、相対力）と呼ばれる比率として比較します:

```
RS = average gain / average loss
```

そしてその比率は0〜100のスケールに圧縮されます:

```
RSI = 100 - (100 / (1 + RS))
```

実際に計算してみましょう。過去14本のバーで、ウィンドウ内の平均上昇幅が$2.40、平均下落幅が$1.20だったとします。上昇幅は下落幅のちょうど2倍のペースです:

- RS = 2.40 / 1.20 = **2**
- RSI = 100 − (100 / (1 + 2)) = 100 − (100 / 3) = 100 − 33.3 = **66.7**

この平均について、2つの細かい点があります。まず、上昇したバーの本数ではなく、ルックバック期間全体で割ります — 合計$21.60の上昇バーが9本あったとしても、平均上昇幅は21.60 / 14 = $1.54であり、$2.40ではありません。次に、最初の計算の後、ワイルダーはゼロから再計算するのではなく、平滑化した移動平均を使います: 新しい平均は「前の平均 × 13 + 最新バーの値」を14で割ったものです。この平滑化があるため、RSIは生の価格ほどガタガタと動きません。

## 0〜100のスケールが思ったほど直線的ではない理由

この計算式は、上限のない比率を有限の範囲に押し込みますが、それは均等な圧縮ではありません。3つの基準点を覚えておく価値があります:

<div class="table-wrap">

| 条件 | RS | RSI |
|---|---|---|
| 平均上昇幅と平均下落幅が等しい | 1.00 | 50.0 |
| 平均上昇幅が平均下落幅の2.33倍 | 2.33 | 70.0 |
| 平均上昇幅が平均下落幅の0.43倍 | 0.43 | 30.0 |

</div>

中央の行を確認しましょう: 1 + 2.333 = 3.333、100 / 3.333 = 30、よってRSI = 100 − 30 = 70。下の行: 1 + 0.4286 = 1.4286、100 / 1.4286 = 70、よってRSI = 30。

これが何を意味するか注目してください。70を表示するには、上昇幅が下落幅のわずか2倍強であればよいのです — これはよくある状況であり、極端なものではありません。その先ではスケールが大きく圧縮されます: 70から90に押し上げるには、RSが2.33から9まで動く必要があり、これは表示上の20ポイントの動きが示唆するよりも、はるかに大きなマーケットの変化です。

## 70と30が法則ではなく慣習である理由

ワイルダーは70と30を選びました。75と25を選ぶこともできたはずです。その背後に導出過程はなく、行動が変化する統計的な閾値もなく、70.0でオンになり69.9でオフになる仕組みもありません。それらは、彼が1970年代に研究していたチャート上でそれらしく見えたキリの良い数字であり、誰もがデフォルト設定をそのまま踏襲したために定着しました。ほとんどのチャートソフトはそれらの線を自動的に描画し、それが境界線であるという印象を静かに強化しています。Stockadeのチャートも同様です — 下部パネルをRSIに切り替えると、70と30に破線が表示されます。それらは判定ではなく、目安の線です。

14期間というルックバックについても同じことが言えます。7のような短い設定はより速く反応し、常に極値に達します。21のような長い設定はめったに極値に達しません。期間はシグナルを目にする頻度を変えるのであって、その信頼性を変えるわけではありません — これは[移動平均の期間の選び方](/blog/moving-averages-ema-vs-sma)を左右するのと同じトレードオフです。

## 買われすぎは「強さ」を意味し、「反転間近」ではない

これこそ、冒頭の取引が間違えたポイントであり、それ自体の計算を見る価値があります。

強い上昇トレンドを想像してください: ルックバック期間中、12本のバーが上昇で引け、2本が下落で引けたとします。上昇幅の合計は$28.00、下落幅の合計は$2.80です。

- 平均上昇幅 = 28.00 / 14 = **$2.00**
- 平均下落幅 = 2.80 / 14 = **$0.20**
- RS = 2.00 / 0.20 = **10**
- RSI = 100 − (100 / 11) = 100 − 9.1 = **90.9**

では、RSIを70未満に戻すには何が必要か考えてみましょう。上の表から、RSは10から2.33まで下がる必要があります — 平均下落幅が平均上昇幅に対して4倍以上に増える必要があるということです。平滑化された14本平均では、これには本当に異なる値動きが何本も必要です。陰線が1本出たくらいでは起こりません。

つまり、RSIはトレンド中に70を超えた状態を単に許容しているのではなく、値動きの性質が変わるまで、算術的にそこに固定されているのです。トレーダーはこれをRSIの「埋め込み（embedding）」と呼びます。90という数値は、トレンドが異例なほどきれいであることを示しており、きれいなトレンドこそ最も逆張りすべきでないものです。

同じ罠のもっと分かりにくいバージョンもあります。RSIが66.7（平均上昇幅$2.40、平均下落幅$1.20）にあり、次のバーが$1.00上昇して引けたとします。平滑化を適用すると: 新しい平均上昇幅は (2.40 × 13 + 1.00) / 14 = 32.20 / 14 = $2.30、新しい平均下落幅は (1.20 × 13 + 0) / 14 = 15.60 / 14 = $1.114です。RS = 2.30 / 1.114 = 2.064なので、RSI = 100 − (100 / 3.064) = **67.4**です。

価格は上昇したのに、RSIはほとんど動きませんでした。上昇幅が移動平均の上昇幅より小さかったからです。RSIは価格ではなく、モメンタムを追跡します。価格が新高値を更新する一方で、RSIが横ばいになったり下落したりすることがあります — それがまさに、人々がダイバージェンスと呼ぶ状況です。

## RSIダイバージェンスの読み方

ダイバージェンスとは、価格とモメンタムの不一致です。

**弱気のダイバージェンス:** 価格はより高い高値をつけるが、RSIはより低い高値をつける。価格はより遠くまで進んだが、前回より勢いが弱いということです。

**強気のダイバージェンス:** 価格はより低い安値をつけるが、RSIはより高い安値をつける。売り手は再び価格を押し下げたが、その確信は弱まっているということです。

ダイバージェンスを読むには、価格上で同種の2つのスイングポイント — 2つの明確な高値、または2つの明確な安値 — に印をつけ、それぞれのRSIを比較します。それが意味を持つのは、両者が比較可能なスイングであり、その間に実際の押し目・戻りがある場合だけです。任意のバー同士を結べば、ほとんどどんなチャートでもダイバージェンスは作り出せてしまいます。だからこそ後知恵では非常に見つけやすいのです。

的中率について率直に言えば: ダイバージェンスはよく失敗し、最も魅力的に見える場面でこそ最悪の失敗をします。強いトレンドは、上昇の過程で3〜4回の弱気ダイバージェンスを出しますが、意味を持つのは最後の1回だけです — それより前のものはすべて、お金を失う罠です。ダイバージェンスは、トレンドに逆張りする単独のエントリー根拠としてではなく、ストップを締める、あるいは勝ちポジションへの追加をやめる理由として扱いましょう。ダイバージェンスシグナルを根拠に強さに逆張りすることは、[新米トレーダーが身につけてしまいがちな、より高くつく習慣](/blog/common-day-trading-mistakes)の1つです。

## 50ラインをトレンドフィルターとして使う

最も役立つRSIの水準は、誰も線を引かないものです。RSI 50は、平均上昇幅と平均下落幅がちょうど等しくなる点です。それより上では上昇幅が優勢であり、それより下では下落幅が優勢です。

そのため、50は手軽なレジームフィルターになります:

- **RSIが継続して50超え** — 30は到達不可能なものとして扱い、売られすぎのロングを探すのをやめましょう。上昇トレンドでは、押し目は40〜50付近で底を打つ傾向があります。
- **RSIが継続して50未満** — 鏡写しの状況です。戻りは50〜60付近で失速し、70に届くことはありません。

この非対称性は、極値よりも実行可能な情報です。上昇トレンドでは、RSIが45まで下がって持ちこたえ、そこから上向く動きは、強いトレンド内での押し目の終わりを示します。そこで30を待つことは、そのトレンドが生み出さない数値を待つことに等しいのです。

### 閾値を80/20にシフトする

閾値が慣習にすぎないと受け入れれば、それを調整するのは自然なことです。強いトレンド相場では、バンドを80と20に動かしましょう。シグナルの数は大きく減りますが、得られるシグナルは日常的なトレンドの強さではなく、本当に異例な数値を示すものになります。レンジ相場ではデフォルトの70/30の方がうまく機能します。そこでは平均回帰が実際に支配的な動きだからです。

順序が重要です: まずレジームを特定し、それから閾値を選びます。RSIでレジームを判断し、同じRSIを使ってそのレジームに逆張りするのは、循環論法です。

## RSIにできないこと

RSIは、すでに見た終値だけから構成されています。それは遅行性の派生指標であり、すべての値は過去についての事実です。バー内の値動きは見えず、価格系列にすでに含まれていない情報は一切持っていません。

また、なぜ価格が動いたのかという概念も持っていません。着実な上昇から生まれた90.9という数値も、1回の窓開け（ギャップ）から生まれたものも、計算式にとっては同じに見えます。だからこそRSIは、価格構造や出来高と併せて読む価値があり、また上昇・下落の比率ではなく2本の移動平均の差を測る[MACD](/blog/macd-explained)との違いを知っておく価値があります。

## シミュレーターでRSIの読み方を練習する

「70は売り」という思い込みを最も早く取り除く方法は、価格が上昇する中でRSIが40本のバーにわたって70を超え続けるのを観察することです。[Stockadeの株式市場シミュレーター](/ja/simulator/)を開き、下部のチャートパネルを出来高からRSIに切り替え、ラインが70を超えて埋め込まれている区間を見つけましょう — そして、RSIが50に戻るまでに価格がどれだけ進むかを記録します。逆の練習もしてみましょう: 上昇チャート上のすべての弱気ダイバージェンスに印をつけ、実際に下落が続いたものが何回あったかを数えてください。価格は実際の市場データではなくアルゴリズムで生成されたものですが、インジケーターの計算式は同一であり、その回数を数えることであなたのツールの使い方は変わるはずです。
